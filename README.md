# Интернет-магазин — вариант 1

Java 21, Maven, JUnit 5. Учебный проект интеграционных тестов. Три модуля находятся в Store.java: Search, Cart, Checkout. Тесты используют реальные модули совместно, заменяя только внешнюю оплату и почту тестовыми адаптерами.

## Запуск в IntelliJ IDEA
1. File → Open → выбрать pom.xml этого проекта → Open as Project.
2. Project SDK: Java 21. Дождаться загрузки Maven.
3. Открыть StoreIntegrationTest и нажать зеленую кнопку запуска класса.

Из PowerShell в папке проекта: `mvn test`.
Отчет: target/surefire-reports. Каждый тест пишет журнал во временную папку JUnit.

## Правила, уточняющие ТЗ
- Поиск без учета регистра, по подстроке названия; категория — точное совпадение. Цены включают обе границы. Критерии объединяются через И.
- Релевантность: точное название, начало названия, затем вхождение. Внутри группы цена возрастает; при равенстве используется ID.
- В тестах налог 20%, скидка 10% при сумме от 2000. Ставки передаются конструктору. Сначала скидка, затем налог; округление HALF_UP до двух знаков.
- Количество — положительное целое. Нулевое количество отклоняется; удаление отдельной операцией.
- Карта проверяется по формату, алгоритму Луна, сроку и CVV. PayPal — формат email. Адрес: обязательные страна, город, улица и индекс из 3–12 допустимых символов.
- Корзины разделены по идентификатору пользователя; операции одной корзины и оформление синхронизированы. Каталог неизменяемый, хранилища потокобезопасные.
- При отказе платежа корзина сохраняется. При сбое почты уведомление помещается в очередь повторной отправки без повторной оплаты.

## Границы учебной реализации
PaymentGateway и EmailSender — интерфейсы внешних систем. В тестах платежи имитируются, письма попадают в проверяемый локальный список. Реальные PayPal/эквайринг и SMTP не подключены. Заказы, корзины и очередь уведомлений хранятся в памяти. Это проект для интеграционного тестирования, без веб-интерфейса и базы данных.

## Покрытие требований
StoreIntegrationTest проверяет поиск и сортировку, переход из поиска в корзину, изменение и удаление товаров, налоги и скидки, оба способа оплаты, невалидные данные и отказ платежа, состав email, повторную отправку, параллельные покупки 24 пользователей, конкурентное изменение корзины и файловый журнал без платежных секретов.
